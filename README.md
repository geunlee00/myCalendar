# 바탕화면 달력 위젯

Windows용 WPF 기반 달력·할 일 위젯입니다. 스프링 고리와 미색 종이, 줄 노트 메모장을 단 탁상 달력 모양입니다.

## 현재 기능

### 바탕화면 고정
- 바탕화면 아이콘 층 안에 끼워 넣어 바탕화면의 일부처럼 동작
  - 다른 앱 창 위로 올라오지 않음 (위젯을 클릭하거나 입력하는 중에도)
  - `Win + D`(바탕화면 보기)를 눌러도 숨겨지지 않음
- 위쪽(스프링 아래 여백이나 큰 월 숫자 부분)을 끌어서 옮기고, 오른쪽 아래 모서리를 끌어서 크기 조절
- 옮긴 위치와 크기를 기억 (`⋯` 메뉴의 "위치·크기 처음으로"로 되돌리기)
- `⋯` 메뉴의 슬라이더로 배경 투명도 조절 (글자는 또렷하게 유지, 투명할수록 글자 둘레에 흰 빛)
- 처음 실행할 때 Windows 시작 시 자동 실행을 켬 (`⋯` 메뉴에서 끄고 켜기)
- 이미 실행 중이면 두 번째 실행은 바로 끝남
- 탐색기가 다시 시작되면 바탕화면에 자동으로 다시 붙음

### 달력
- 날짜 칸 안에 그날 일정 제목 표시 (칸에 다 안 들어가면 "+N개 더")
- 한국 공휴일·대체공휴일을 빨간 날로 표시 (설날·추석·부처님오신날은 음력 계산, 임시공휴일은 제외)
- `오늘` 버튼, 달력 위에서 마우스 휠로 달 이동
- 자정이 지나면 오늘 표시가 자동으로 넘어감

### 할 일
- 선택한 날짜의 할 일만 목록에 표시
- 날짜 더블클릭 → 바로 입력칸으로, Enter로 추가
- 할 일 이름 더블클릭 → 이름 고치기 (Enter 저장, Esc 취소)
- 완료한 일은 줄을 긋고 목록 아래로
- 바꿀 때마다 바로 저장 (`%LOCALAPPDATA%\CalendarWidget\tasks.json`)
  - 저장 파일이 손상되면 지우지 않고 `tasks.json.broken-날짜`로 보관

## 실행

개발용 **.NET 10 SDK**가 필요합니다. 프로젝트 폴더에서 실행합니다.

```powershell
dotnet run
```

빌드한 뒤에는 `bin\Debug\net10.0-windows\CalendarWidget.exe`를 바로 실행해도 됩니다.
자동 실행도 이 파일을 등록하므로, 폴더를 옮기면 메뉴에서 자동 실행을 껐다 다시 켜야 합니다.
